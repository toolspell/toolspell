# Toolspell

## Development

- [Vite+](https://viteplus.dev) is required
- Vite+ manages node version and package manager

- Install packages

```bash
vp install
```

- Check everything is ready:

```bash
vp run ready
```

- Run the tests:

```bash
vp run -r test
```

- Build the monorepo:

```bash
vp run -r build
```

- Run the development server:

```bash
vp run dev
```
